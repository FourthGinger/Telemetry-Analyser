# Telemetry-Analyser
A Python-based telemetry analyser for loading, viewing and analysing racing telemetry data from CSV files.

The project currently provides a simple graphical interface for:

- Loading telemetry CSV files
- Reading telemetry channels from the file
- Displaying telemetry data as graphs
- Selecting multiple telemetry channels to display on the same graph
- Viewing file information such as the sample rate

The project is currently under development, with additional telemetry analysis and visualisation features planned for future versions.

The project currently only supports CSV files exported through MOTEC.
